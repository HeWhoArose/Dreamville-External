**Phase 1A: LARGELY IMPLEMENTED AND PROVEN AT THE MOCKED LIVE-ROUTE LEVEL (the plan's own Gate statement — "Live /api/game/action tests prove a single production path, no third repair call, consistent state/narration, and safe provider-failure behaviour" — passes this checkout).**

Residuals that keep it below "fully complete":

2. plot.beat delivery via `ActionResolution/commitRecords` on the production freeform route is not wired (deferred to Phase 1D by the plan, but it is the biggest remaining item under Phase 1A item 2).
3. Observation-result *detection* is still lexical (half of the "replace brittle lexical assumptions" item).
4. Single-rewrite consequence-coverage gap demonstrated by `world-director.test.ts:2417` (safe fallback works; repair completeness does not).
5. Housekeeping: stale `aiOrchestrator.ts:9443` comment; two brittle source-regex tests to modernise (one stale, one CRLF-sensitive); marathon perf budget to measure serially.
6. No real-provider (live) Phase 1A run recorded — required before declaring Phase 1A closed under §9.6.
